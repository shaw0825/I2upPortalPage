# Information2 统一数据管理平台

Information2 企业级数据产品 Portal 原型。管理员登录后可从统一门户访问容灾备份、数据集成等产品；超级管理员还可以配置产品卡片、展示状态、顺序以及每个产品对应的多个访问入口。

## 功能概览

### 登录与权限

- 支持 `admin` 和 `sysadmin` 两个演示账号。
- 两个账号的默认密码均为 `Info1234`。
- `admin`：仅可访问产品门户。
- `sysadmin`：可访问产品门户和产品配置页面。
- 支持锁定、退出登录和账户下拉菜单。

> 当前登录流程为前端原型，仅用于界面和权限流程演示，不应作为生产环境认证实现。

### 产品门户

- 展示当前启用的产品卡片。
- 默认展示：
  - 容灾备份
  - 数据集成
- 数据迁移、数据脱敏默认隐藏，可由 `sysadmin` 开启。
- 产品卡片支持能力标签、主题色和产品描述。
- 支持一个产品配置一个主入口和多个子入口。
- 点击主入口按钮可选择不同业务控制台。

### 产品配置

仅 `sysadmin` 可访问。

- 新建和编辑产品卡片。
- 配置产品名称、英文标识、描述和主题色。
- 配置主入口名称与访问链接。
- 每个产品最多可增加 5 个子入口。
- 控制产品卡片是否在 Portal 展示。
- 通过拖拽调整产品卡片顺序。
- 配置修改后同步更新 Portal 卡片和入口菜单。

## 核心数据模型

每个产品卡片由产品信息和入口列表组成：

- 产品名称、描述、能力标签和主题色。
- 产品来源：内置产品或后台配置。
- 展示状态和排序。
- 一个始终保留的主入口。
- 零到五个可配置子入口。
- 每个入口拥有独立名称和访问链接。

## 原型限制

- 登录账号与密码保存在前端代码中。
- 产品配置仅保存在当前浏览器运行状态，刷新后会恢复默认数据。
- 产品入口跳转目前使用提示信息模拟，尚未连接真实产品地址。
- 主题、语言、通知和帮助为界面交互原型。
- 尚未连接后端数据库、认证服务、单点登录或配置管理接口。

生产化时应将账号认证、权限校验、产品配置、排序、入口地址和单点登录流程迁移至服务端，并对所有管理接口执行服务端权限校验。
